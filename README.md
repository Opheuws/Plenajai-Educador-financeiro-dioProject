Este é um projeto do BootCamp Santander Ai: React front-End

Link de amostra da aplicação:
https://opheuws.github.io/Plenajai-Educador-financeiro-dioProject/

O objetivo deste projeto final é desenvolver um Educador financeiro com IA generativa, com a capacidade de Receber os dados do usuário de renda, custos fixos e dividas, além de um objetivo e em quanto tempo quer realizar esse objetivo

Com estes dados a aplicação ultiliza a IA generativa do Google Gemini no plano gratuito para gerar a analise dizendo se este objetivo é ou não viavel no periodo informado,
dicas do que a pessoa pode fazer, porcentagem de sua economia ou gastos e etc...

O maior desafio estava em criar, ao fim do projeto a página de Histórico seguindo os padrões de layout da aplicação e desenvolver para que seja possivel que o usuário possa conversar com IA a partir da resposta que a mesma fornece.

Além disso teve o desafio que me propus a realizar de fazer o Deploy da aplicação no GitHub (fazer com que as pessoas possam visualizar a aplicação funcionando no proprio GitHub)
Sendo nescessários fazer outras modificações de rota no projeto, salvar a chave da API ultilizada nos 'Secrets' de ações do Repositório, corrigir erros de building e Rota e o link de acesso.

Técnologias usadas no projeto incluem: VITE, TypeScript, Tailwind (Framework de biblioteca de classes CSS), REACT Skeleton LIbrary, ESLINT  & BABEL, FontSource/inter

Os cursos No BootCamp foram direcionados pela @micheleambrosio: https://github.com/micheleambrosio
